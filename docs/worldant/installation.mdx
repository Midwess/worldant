---
title: Installation
description: Install and verify the Worldant command-line tool.
---

Install the public package:

```bash
npm install --global @midwess/worldant-cli
worldant --version
```

The package installs a verified release binary together with the native TypeScript checker bundle
for that target. Release and checker manifests pin and verify the executable, TypeScript-Go commit,
Go toolchain, diagnostic protocol/policy, standard declarations, licenses, and SHA-256 digests.
The bundle also pins the matching Bun/Node host declarations and verifies their complete
content-addressed inventory before use. Worldant never searches `PATH`, Node, npm, or the network
for a checker at authoring time.

Use:

```bash
worldant init todo
cd todo
worldant build
worldant serve
```
