---
title: Quickstart
description: Create, build, serve, and call a minimal Worldant world.
---

Create a world:

```bash
worldant init todo
cd todo
```

`init` downloads the latest public template and creates a single-app world:

```text
todo/
  worldant.ts
  migrations/
  commands/
  workflows/
    steps/
  lib/
  tests/
```

Add a migration under `migrations/0001_init.sql`:

```sql
create table todo_items (
  id bigint generated always as identity primary key,
  title text not null,
  done boolean not null default false,
  created_at timestamptz not null default now()
);
```

Add a Command under `commands/add.ts`:

```ts
import { db, sql } from "worldant"

export default async function add(input: { title: string }) {
  return db.one(sql`
    insert into todo_items (title)
    values (${input.title})
    returning id, title, done, created_at
  `)
}
```

Build and serve:

```bash
worldant build
worldant serve
```

Call it:

```ts
import { createWorld } from "worldant-client"

const world = createWorld({ url: "ws://127.0.0.1:8787/__worldant/v1/ws" })
const todo = await world.todo.add({ title: "Buy milk" }, { key: "todo:add:buy-milk" })
```

Use Workflows for work that must survive retries, waits, process failure, or restart.
